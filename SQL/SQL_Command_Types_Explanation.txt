
SQL Command Types in MySQL
===========================

1. DDL (Data Definition Language)
----------------------------------
These commands define or change the structure of database objects such as tables and schemas.

Examples:
- CREATE:
  CREATE TABLE Students (ID INT, Name VARCHAR(100));

- ALTER:
  ALTER TABLE Students ADD COLUMN Age INT;

- DROP:
  DROP TABLE Students;

- TRUNCATE:
  TRUNCATE TABLE Students;

- RENAME:
  RENAME TABLE Students TO Alumni;

2. DML (Data Manipulation Language)
------------------------------------
These commands are used to manipulate data stored in the database.

Examples:
- SELECT:
  SELECT * FROM Students;

- INSERT:
  INSERT INTO Students (ID, Name, Age) VALUES (1, 'John', 20);

- UPDATE:
  UPDATE Students SET Name = 'Jane' WHERE ID = 1;

- DELETE:
  DELETE FROM Students WHERE ID = 1;

3. TCL (Transaction Control Language)
--------------------------------------
These commands manage transactions in the database.

Examples:
- COMMIT:
  COMMIT; -- Saves all changes made during the current transaction

- ROLLBACK:
  ROLLBACK; -- Undoes changes made during the current transaction

- SAVEPOINT:
  SAVEPOINT sp1; -- Sets a savepoint
  ROLLBACK TO sp1; -- Rolls back to that savepoint

- SET TRANSACTION:
  SET TRANSACTION READ ONLY;

4. DCL (Data Control Language)
-------------------------------
These commands control access to data within the database.

Examples:
- GRANT:
  GRANT SELECT, INSERT ON Students TO 'user1'@'localhost';

- REVOKE:
  REVOKE INSERT ON Students FROM 'user1'@'localhost';

5. DRL (Data Retrieval Language)
--------------------------------
Sometimes classified separately, this primarily involves the SELECT statement.

Example:
- SELECT:
  SELECT Name, Age FROM Students WHERE Age > 18;

Summary Table:
--------------
| Type | Full Form                   | Commands                          |
|------|-----------------------------|-----------------------------------|
| DDL  | Data Definition Language    | CREATE, ALTER, DROP, TRUNCATE     |
| DML  | Data Manipulation Language  | SELECT, INSERT, UPDATE, DELETE    |
| TCL  | Transaction Control Language| COMMIT, ROLLBACK, SAVEPOINT       |
| DCL  | Data Control Language       | GRANT, REVOKE                     |
| DRL  | Data Retrieval Language     | SELECT                            |
